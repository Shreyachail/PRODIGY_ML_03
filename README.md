## 📌 Project Overview
This project implements a Support Vector Machine (SVM) to classify images of cats and dogs using image processing and machine learning techniques.

The project explores image features, including Histogram of Oriented Gradients (HOG), and compares Linear SVM and RBF Kernel SVM models.

## 🎯 Objectives
- Load and explore the Cats vs Dogs image dataset.
- Preprocess images and extract numerical features.
- Train Linear SVM and RBF Kernel SVM classifiers.
- Evaluate model performance using accuracy and classification metrics.
- Visualize model performance using a confusion matrix.

- Scikit-learn
- Scikit-image
- Support Vector Machine (SVM)
- Histogram of Oriented Gradients (HOG)

## ⚙️ Methodology
1. Dataset loading
2. Image preprocessing

4. Splitting data into training and testing sets
5. Training Linear SVM and RBF SVM
6. Evaluating classification performance
7. Visualizing the confusion matrix
